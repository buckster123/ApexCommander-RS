# ApexCommander-RS — pre-next-slice audit (2026-08-15)

> Read-only review of `main` @ `2779cc0` before further development.
> S5 (`fix/s5-policy-honesty`) implements the blocking items below.
> Where this file and later code disagree, the later dated charter/design
> amendment wins — this page is the finding, not a second contract.

**Verdict:** S0–S4 shipped a real, GNOME-proven catalog (~5.7k LOC, 30 unit
tests, 22 MCP tools, ubuntu:GNOME Wayland field PASS). The safety story
README / skill / D7 sell was **not** what the code did. Do not start P4
(daemon, presence, Electron, Windows) until D7 actually matches window
titles.

## P0 — denylist looked at the wrong string

`do_action` / `type_into` / `set_value` called `guard_name(element_id)`.
Ids are `{bus}|{path}` (e.g. `:1.11|/org/a11y/atspi/accessible/943`) and
almost never contain `bitwarden` / `1password`. `guard_window` (title +
app name) existed and was unit-tested, then unused on the live path.

No policy at all on `activate`, `screenshot`, `mouse_*`, `type_text`, `key`.
`allow_override` was silent (gotcha claimed it was audited). `type_text`
wrote the typed string into audit `detail` via `run_cmd` argv formatting.

`field_report` advertised `readOnlyHint: true` while calling GrabFocus and
writing a PNG. `destructiveHint` was always `false`.

## P1 — honesty / contract drift

- Charter D5 backend traits were never written (concrete modules only).
- Screenshot name/pid resolution first-matched; `activate` correctly returned
  `Ambiguous`.
- GrabFocus D-Bus `NotSupported` became `HarnessError::Other`; field-report
  string-matched the error to keep the matrix green.
- `find_elements` silently raised `max_nodes`/`max_depth`.
- CLI `--json` was a no-op (`emit` always printed JSON).
- `click_element` lived on the CLI only; required a literal action name
  `click` (no Press/Activate fallback).
- `AtspiSession::connect` sets session `IsEnabled` — `doctor` is not
  side-effect free.
- Input/capture probes are “binary/name present”, not “this call will work”.

## P2 — scale

The MCP process is already long-lived, yet every `tools/call` reconnected
AT-SPI. Process-local reuse is not a daemon (D9).

## S5 scope (this branch)

1. Classify by **window title + app name** (bus-matched windows for element
   ids). Fail closed when the target cannot be classified.
2. Same guard on targeted perception (`snapshot` / `find` / `screenshot`)
   and on full-display capture / coordinate input via **frontmost**.
3. Audit `allow_override`. Require a writable audit log *before* mutating.
   Never put typed text in audit/result detail.
4. Honest GrabFocus (`NotSupported` → `ActivateResult.ok = false`).
   Shared `resolve_window` (Ambiguous) for capture. No silent find budgets.
5. Hold one `AtspiSession` in the MCP process; reconnect on error.
6. `field_report` is not read-only. `click_element` on MCP. Doctor reports
   policy + audit posture. `Protected` values redacted as `[redacted]`.

Out of S5 (still parked): compositor `WindowBackend` (hyprctl / KWin),
warm daemon, presence indicator, Plasma/Hyprland live rows.
